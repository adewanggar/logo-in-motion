# Logo bumper — Remotion project

```bash
npm install
npm run dev                                  # Remotion Studio
node scripts/qa.mjs all --aspect 16x9        # QA frames + Final Frame Contract
npx remotion render src/index.ts PopLockup-16x9 out/PopLockup-16x9.mp4
```

| File | Purpose |
|---|---|
| `src/brand.ts` | name, tagline, colors, font, personality, lockup orientation |
| `src/logo/parts.ts` | logo as a list of actors — generated by `scripts/svg_to_parts.py` |
| `src/bumpers/*.tsx` | 8 patterns: InkDraw, Assemble, PopLockup, Collapse, Sheen, Slam, Converge, IconMorph |
| `src/logo/icons.ts` | icons that IconMorph turns into the logo parts (single closed contour, 100×100) |
| `src/lib/morph.ts` | shape morphing: resample, match point order, lerp |
| `src/bumpers/moves.ts` | shared moves: pop, cascade, slide, shockwave |
| `src/lib/tokens.ts` | personality → easing / timing tokens |
| `src/lib/timeline.ts` | lead · 20:50:30 reveal · hold ≥ 1 s · exit |
| `src/sound.ts` | SFX cues pinned to bumper markers |
| `public/audio/CREDITS.md` | source + license of every audio file |

Render props (`--props='{…}'`): `outro` (`hold|fade|lift|iris`), `seconds`, `showTagline`,
`transparent`, `grain`, `sfx`, `bgm`.

Compositions: `<Pattern>-16x9 | -9x16 | -1x1`, `LogoStill-<aspect>` (static reference),
`LogoCheck` (logo alone at source size, for geometry QA).
